# Formula 1 Object Detection & Trajectory Analysis

## Project Overview

- This repository contains a computer vision project for detecting and tracking Formula 1 cars in broadcast footage and visualizing their trajectories.

## Goal

- Detect Formula 1 cars from video footage
- Track cars across consecutive frames
- Extract and visualize car trajectories

## Methods

- YOLO object detection
- Bounding box and center-point extraction
- Multi-object tracking
- Persistent car ID assignment
- Trajectory trail visualization
- Frame-by-frame video processing

## Tools

- Python
- YOLO / Ultralytics
- OpenCV
- Jupyter Notebook
- Google Colab

## Current Status

- Experimental implementation developed in VS Code
- Further development will focus on improving tracking robustness and extracting structured trajectory data for analysis
